name: catch-up
description: The user calls this when they need you to summarize what's happened since their last message
disable-model-invocation: true
---

The user invoked this skill because there have been a lot of messages since they last talked to you and they haven't read them all.  Give the user a summary of the important stuff that's happened since their last message.  Don't just produce a list of everything that happened, limit it to what the user needs to know.  At the end, include a list of what you need from them.
